# Modules
Modul pada dasarnya hanyalah file Python biasa berekstensi `.py`.
- Built-in Modules: Modul bawaan yang sudah diisntal bernama Python (seperti `math`, `as`, `sys`, `time`).
- Custom Modules: File Python buatan Kita sendiri yang berisi fungsi/class untuk digunakan di file lain.

Blok `if __name__ == "__main__":` adalah trik rahasia Python. Blok ini memastikan bahwa baris kode di dalamnya hanya akan dieksekusi jika file tersebut dijalankan secara langsung bukan ketika di-import oleh file lain.
