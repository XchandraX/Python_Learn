# Algoritma pengurutan (Sorting Algorithms)
fondasi penting dalam ilmu komputer. Tujuannya sederhana: mengatur sekumpulan data acak (seperti deretan angka atau huruf) menjadi urutan tertentu, biasanya dari terkecil ke terbesar (ascending) atau sebaliknya (descending).

Kita memang bisa menggunakan fungsi bawaan `sort()` atau `sorted()` yang menggunakan algoritma super cepat (Timsort). Namun, mempelajari algoritma dasar seperti Bubble Sort dan Merge Sort sangat krusial untuk melatih logika berpikir dan pemahaman tentang efisiense kode.
