# Paradigms
Rangkuman, arsitektur perangkat lunak berbasis OOP selalu dibangun di atas 4 pilar utama
1. Encapsulation (Pembungkusan): Mengikat data dan metode dalam satu wadah (Class), serta menyembunyikan state internal yang sensitif (Private attrivutes).
2. Abstraction (Abstraksi): Menyembunyikan kerumitan proses di balik layar dan hanya menampilkan tombol (interface) yang mudah digunakan pengguna. (Contoh: Kita tidak perlu tahu cara kerja transmisi saat menekan pedal gas).
3. Inheritance (Pewarisan): Menurunkan sifat dari Class Induk ke Class Anak untuk mendaur ulang kode.
4. Polymorphism (Banyak Bentuk): Kemampuan objek dari Class yang berbeda untu kmerespon metode dengan nama yang sama, tetap idengan cara mereka masing-masing.
