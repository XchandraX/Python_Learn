# Classes Objects (Fundamental Class & Object)

Class adalah sebuah cetak biru (Blueprint) atau cetakan. Sama seperti cetak iru arsitek untuk membuat rumah. Class tidak memiliki wujud fisik: ia hanya mendefinisikan apa yang akan dimiliki rumah tersebut (jumlah pintu, warna dinding).

Object (Objek/Instance) adalah wujud nyata yang diciptakan dari cetak biru tersebut. Dar isatu Class Mobil, Kita bisa membuat banyak objek sepert iavanza_saya (berwarna hitam) atau pajero_kamu (berwarna puthi)

## Fungsi __init__ dan parameter self:
- __init__ (Constructor): Fungsi ajaib yang otomatis dijalankan pertama kali saat sebuah objek diciptakan. Ibaratnya pabrik, ini adlaah tahap perakitan di mana kita memasang warna, mesin, dan roda.

- self: Kata ganti untuk objek itu sendiri. Ketika avanza_saya memanggil metode, self meuruk pada avanza_saya. Ini cara objek membedakan datanya dengan objek lain.
